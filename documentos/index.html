Documentos del proyecto

ÉPICA24 · para docentes

Aquí está todo lo que hace falta para repetir el proyecto en otra institución: el prompt con el que se generan los juegos, los datos exactos que se le dieron para cada área, y las instrucciones para publicar un juego en internet.

PDF El promptLas instrucciones completas que se le dan a la inteligencia artificial para que construya un juego. Es el producto central del proyecto. PDF Configuraciones por áreaLos datos que se le dieron al prompt para generar cada uno de los cuatro juegos: tema, grado, niveles y errores a corregir. PDF Cómo publicar un juegoGuía paso a paso para subir un juego a internet con GitHub Pages y obtener un enlace, sin saber programar.
